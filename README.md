# DevConf 2026 Landing Page

A modern conference landing page built with **HTML5** and **CSS3**. This project presents a fictional developer conference website featuring speaker profiles, ticket pricing, conference highlights, and a professional landing page layout.

The project was built to strengthen my frontend development skills by practicing semantic HTML, reusable CSS components, Flexbox, and CSS Grid.
